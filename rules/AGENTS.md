# Finance Bro Equity Research Conventions

When running any Finance Bro equity research skill (`ips-setup`, `equity-screener`, `equity-analyst`, `research-report`, or `equity-research-pipeline`):

1. **Script Resolution:** Execute bundled PEP 723 Python scripts with `uv run <scripts_dir>/<script>.py` (where `<scripts_dir>` is `./src` if present in the active workspace, otherwise the `scripts/` folder beside `skills/` inside this package).
2. **Artifact Paths in Active Workspace:**
   - `memory/client_ips.md` — validated hybrid YAML + Markdown Investment Policy Statement
   - `memory/<TICKER>/` — downloaded SEC filings, XBRL facts JSON, consensus/Reverse DCF JSON, peer comps JSON, `analyst_dossier.md`, `valuation_spec.json`, `valuation_summary.json`, `report_draft.md`, and `report_audit.json`
   - `Output/models/<TICKER>_valuation.xlsx` — 100% live-formula 5-year Excel valuation workbook
   - `Output/reports/<TICKER>_report.pdf` — numerically audited institutional PDF coverage report
3. **Integrity Rules:** Ground historical numbers in SEC EDGAR (`edgar_client.py`), never hardcode calculated outputs in Excel cells, and keep `audit_report.py --strict-slop` green before final delivery.
4. **Independent Audit Routing (`Claude Sonnet 5.5 High`) & 1-Iteration Master-Agent Rewrite:** When Antigravity `swarm` is available, run both the Stage 2 Screener Audit (`equity-screener` Step 4) and the Stage 4 `show-me-your-work` cross-model trail review via `swarm(action="add", model="claude-sonnet-5-5-high", workspace="inherit", ...)` (swapping the Stage 4 reviewer to `"gemini-4-hydrogen-high"` only if the primary run itself executed on Claude). Instruct the fresh verification worker to push structured actionable feedback directly to `@coordinator` (`memory/screening_audit.md` / `memory/trail_audit.md` + board post), end the turn immediately after `add`, read the board on wakeup, have the **master (coordinator) agent directly rewrite** the screening outputs and report/model deliverables in **at most `1` rewrite iteration** (never bouncing report rewrites back to researcher subagents and never starting a 2nd rewrite cycle), obtain one final confirmatory sign-off check (`VERDICT: PASS`), retire completed audit workers via `swarm(action="kill", name=...)`, and report the verified `reviewed by <model>` slug. Fall back to `claude-opus-5-5-high` or `invoke_subagent(..., Model="pro")` only if `claude-sonnet-5-5-high` lacks quota or `swarm` is unavailable, noting why.
