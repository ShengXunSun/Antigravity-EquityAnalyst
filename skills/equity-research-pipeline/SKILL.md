# End-to-End Equity Research Pipeline Orchestrator

Coordinate the 4-stage institutional equity research workflow across `memory/`, `src/`, `Output/models/`, and `Output/reports/`, automatically advancing every auditor-verified shortlist candidate into parallel research while maintaining an append-only decision trail.

> **Standalone Script Path (`<SCRIPTS>`):** Use `./src` if present in the active workspace; otherwise use the bundled `scripts` directory alongside `skills/` in this package (`<this_skill_dir>/../../scripts`), invoked directly via `uv run <SCRIPTS>/<script>.py`.

## Pipeline Architecture & State Contract

```text
Stage 1: ips-setup        -> memory/client_ips.md
Stage 2: equity-screener  -> memory/screening_results.json + memory/screening_audit.md (verified shortlist auto-advances)
Stage 3: equity-analyst   -> memory/<TICKER>/analyst_dossier.md + Output/models/<TICKER>_valuation.xlsx (5Y Thesis-Linked DCF + Comps) + memory/<TICKER>/valuation_summary.json
Stage 4: research-report  -> Output/reports/<TICKER>_report.pdf + memory/<TICKER>/report_audit.json
```

Maintain one canonical audit trail at `memory/decisions.tsv` via `uv run <SCRIPTS>/decision_log.py`, and run cross-model verification audits (Stage 2 screening + Stage 3–4 research/reports) on **`claude-sonnet-5-5-high`** via `swarm` (`workspace: "inherit"`; swap to `gemini-4-hydrogen-high` only if the primary pipeline itself ran on Claude so review stays cross-family). For **both** screening and reports, run a strict **1-iteration audit-and-rewrite loop**: the verification agent pushes structured actionable feedback directly to the **master (coordinator) agent** (`@coordinator`), and the **master agent directly rewrites** the screening outputs and report/model deliverables based on that feedback before final confirmatory sign-off and delivery to the user (never exceeding `1` rewrite iteration and never bouncing report rewrites back to researcher subagents).

## Ordered Execution Protocol

### Stage 1: Client Mandate (`ips-setup`)
1. Check `memory/client_ips.md` via `uv run <SCRIPTS>/ips_parser.py memory/client_ips.md`.
2. If absent, invalid, or the user requests changes, read and execute `ips-setup/SKILL.md` (or sibling `../ips-setup/SKILL.md`).
3. **Gate to Stage 2:** `ips_parser.py` exits `0`.

### Stage 2: Pre-Screening Batch Cap & 1-Iteration Screening Audit + Master Rewrite (`equity-screener`)
1. If the user already specified exact target ticker(s) to cover, proceed directly to Stage 3 against `memory/client_ips.md` (or ask whether to run the full screen if ambiguous).
2. Otherwise, **before screening starts** (unless the user already specified a numeric limit `N` in their request), call `ask_question` to ask the **maximum number of companies (`N`) to research at once** (e.g., `"3 companies (Recommended — balanced parallel wave)"`, `"5 companies (Max single parallel wave)"`, `"1–2 companies (Deep focus pair)"`; the UI lets the user enter another count) so the post-audit handoff never launches too many companies simultaneously. Record the chosen `N` in `memory/decisions.tsv`.
3. Read and execute `equity-screener/SKILL.md` with `max_research_count = N`: build `memory/macro_tailwinds.json`, run `screener.py --top-n <N>`, and dispatch the `claude-sonnet-5-5-high` Verification Agent (`screener-auditor`) via `swarm` (`workspace: "inherit"`, passing full artifact paths in `brief`) to produce `memory/screening_audit.md` and push structured actionable feedback (Must-Fix Defects + Screening/Concentration Improvements) directly to `@coordinator`. **Master-Agent Rewrite (Exactly `1` Iteration):** Keep `screener-auditor` alive on the board; whenever the verification agent flags defects (`VERDICT: REVISE_REQUIRED`) or actionable improvements, the **master (coordinator) agent directly rewrites** the screening inputs/filters/shortlist (fixing macro/screener inputs, replacing flagged tickers `<= N`, re-running `screener.py --top-n <N>` + like-for-like `sanity-check --align-with`, and rewriting `memory/screening_results.json` & `memory/screening_funnel.md`), logs the rewrite in `memory/decisions.tsv`, and posts the updated screening summary to `@screener-auditor` (`post_message`) for one final confirmatory sign-off (`VERDICT: PASS`; never start a 2nd rewrite cycle — log any minor residual notes as watch items) before killing `screener-auditor`. *(If the initial audit already returns `VERDICT: PASS` with zero actionable feedback items, skip rewriting and retire `screener-auditor` immediately.)*
4. **Automated Handoff to Stage 3 (No Human Pause):** Once `memory/screening_audit.md` records confirmatory `VERDICT: PASS` (`<= N` verified finalists in `memory/screening_results.json`), optionally present a compact summary / `generative_ui` scorecard card of the verified finalists and **immediately pass all verified shortlist tickers into Stage 3 without pausing for confirmation** (pause with `ask_question` only if the user explicitly asked to hand-pick finalists).

### Stage 3 & Stage 4: Uninterrupted Analysis, 1-Iteration Report Audit & Master Rewrite (`equity-analyst` -> `research-report`)
1. Once target ticker(s) are confirmed or handed off automatically from Stage 2 (never exceeding `N` screened finalists), establish uniform currency-specific CAPM market anchors (one dated live `Rf`, e.g., `^TNX` for US models, and standardized institutional `ERP`) across the batch, then run Stage 3 (`equity-analyst/SKILL.md`) followed immediately by Stage 4 (`research-report/SKILL.md`) **without mid-run pauses**:
   - **1 ticker:** Execute `equity-analyst` then `research-report` directly (or in a `self` subagent).
   - **2–5 approved tickers (`N <= 5`):** Spawn one `invoke_subagent` (`TypeName: "self"`, `Role: "Equity Analyst & Valuation - <TICKER>"`) per ticker in parallel so each company gets a dedicated context window reading its `10-K`/`20-F`/`10-Q` filings, formulating `T1..Tn` Variant Thesis Pillars, building its 5-year live-formula `.xlsx` model (`Output/models/<TICKER>_valuation.xlsx`), and compiling its initial audited PDF report (`Output/reports/<TICKER>_report.pdf`).
   - **`N > 5` (if explicitly requested):** Execute in chunked parallel waves of up to 5 tickers (or via the built-in `swarm` skill), never exceeding `N` total companies in the run.
2. Verify that for every covered ticker:
   - `valuation_excel.py` passed (`0` formula errors, valid `T1..Tn` Two-Tier assumption linkage, `ebit_includes_sbc` set consistently on GAAP models), and
   - `audit_report.py --strict-slop --export-pdf Output/reports/<TICKER>_report.pdf` exited `0` (`0` numerical/thesis errors, `0` prose warnings).
3. **1-Iteration Cross-Model Report Audit & Master-Agent Rewrite (`show-me-your-work`, Before User Output):**
   - Check `swarm(action="status")` for name collisions, then spawn `swarm(action="add", name="trail-auditor", model="claude-sonnet-5-5-high", workspace="inherit", brief=...)` (or `gemini-4-hydrogen-high` if the primary pipeline ran on Claude, falling back to `claude-opus-5-5-high` or `invoke_subagent(..., Model="pro")` only on 0% quota / `swarm` unavailability). Keep the verification agent active on the board until final sign-off.
   - Instruct the verification agent to audit `memory/decisions.tsv`, `memory/screening_audit.md`, `memory/<TICKER>/analyst_dossier.md`, `valuation_spec.json`, `valuation_summary.json`, `.xlsx`, `report_draft.md`, and `report_audit.json` across all covered tickers—explicitly checking cross-batch `Rf`/`ERP` uniformity, peer Comps multiple time-basis alignment (`trailing` vs `forward`), Exit-Multiple vs Perpetuity implied multiple convergence, SBC/lease/NCI consistency, rating robustness vs IPS hurdles, thesis evidence rigor, prose clarity, and transcript truth—write its structured per-ticker feedback (Must-Fix Defects + High-Value Analytical/Report Refinements) to `memory/trail_audit.md`, and **push the feedback directly to the master agent (`@coordinator`)** on the swarm board with `VERDICT: PASS` or `VERDICT: REVISE_REQUIRED`.
   - **Master-Agent Rewrite (Exactly `1` Iteration — No Subagent Bounce-Back):** When the verification agent pushes feedback (`VERDICT: REVISE_REQUIRED` or actionable analytical/report improvements), do **not** route findings back to researcher subagents via `send_message`. Instead, the **master (coordinator) agent directly rewrites** the affected deliverables in **1 single iteration**: update `memory/<TICKER>/analyst_dossier.md` and `memory/<TICKER>/valuation_spec.json` (plus any shared `src/` fixes if flagged), rebuild `.xlsx` + `valuation_summary.json` via `valuation_excel.py` (`0` error cells), directly rewrite `memory/<TICKER>/report_draft.md` incorporating the feedback agent's critiques (synced with `valuation_summary.json` and `T1..Tn` pillars), and re-run `audit_report.py --strict-slop --export-pdf Output/reports/<TICKER>_report.pdf` (`0` errors, `0` warnings). Log the master-agent rewrite in `memory/decisions.tsv` and post the concise rewrite summary to `@trail-auditor` (`post_message`) for one final confirmatory sign-off (`VERDICT: PASS`; strictly capped at `1` rewrite iteration — never trigger a 2nd rewrite cycle, placing any residual non-blocking watch items into `## Attention`) **before** killing `trail-auditor` and outputting deliverables to the user. *(If initial audit returns `VERDICT: PASS` with zero actionable feedback items, skip rewriting and retire `trail-auditor` immediately.)*
4. After confirmatory `VERDICT: PASS`, deliver clickable links to the updated screening outputs (`memory/screening_funnel.md`, `memory/screening_audit.md`), `memory/trail_audit.md`, and every final 5-year Excel workbook (`Output/models/<TICKER>_valuation.xlsx`) and institutional PDF report (`Output/reports/<TICKER>_report.pdf`), ending with any non-blocking residual watch items / upcoming catalysts in `## Attention` (`reviewed by claude-sonnet-5-5-high`). Optionally offer recurring `10-Q`/`8-K` coverage monitoring via `/schedule` or the `automation` skill.
